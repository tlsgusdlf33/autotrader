# AutoTrader

`AutoTrader.zip` 하나만 올려두면 GitHub Actions 가 알아서 풀어서 APK 를 만듭니다.
자세한 사용법은 zip 안의 `APK만들기.md` 를 보세요.

---

## 고쳐서 다시 깔아도 키·매매법이 남습니다

예전에는 새 APK 를 깔려면 **앱을 지워야** 했습니다. 지우는 순간

- 입력해 둔 API 키·계좌번호
- 엔진 거래 기록(`engine_state.db`) — **어떤 종목을 어떤 매매법으로 샀는지**

가 앱 폴더와 함께 전부 사라졌습니다. 그래서 다시 깔 때마다 키를 새로 넣어야
했고, 계좌에 남아 있던 종목은 '모르는 종목'이 되어 기본 매매법(#16)으로 다시
주워담겼습니다.

원인은 **서명 키**였습니다. 안드로이드는 같은 키로 서명된 APK 만 기존 앱 위에
덮어 설치하게 해주는데, gradle 이 자동으로 만드는 debug 키는 빌드하는 기계마다
새로 생깁니다. GitHub Actions 는 매번 새 기계에서 돌기 때문에, 빌드할 때마다
서명이 달라졌습니다.

지금은 이렇게 동작합니다.

| | 하는 일 |
|---|---|
| `app/autotrader.jks` | 저장소에 함께 둔 고정 서명 키. 항상 같은 서명이라 **덮어 설치**가 됩니다 |
| `APP_VERSION_CODE` | 빌드할 때마다 GitHub 실행 번호가 들어갑니다. 번호가 줄면 설치가 거부됩니다 |
| 자동 백업 | 키와 거래 기록을 암호화해 **다운로드/AutoTrader** 등 세 곳에 남기고, 새로 깔면 스스로 되살립니다 |
| 매매법 되살리기 | 추적이 끊긴 종목을 다시 주워담을 때 **지난 매수 기록**에서 매매법을 찾습니다 |

### ⚠️ 딱 한 번은 지우고 깔아야 합니다

이번 APK 는 예전 APK 와 서명이 다릅니다 — 예전 건 빌드할 때마다 서명이
달랐으니 어차피 맞출 수가 없습니다. **이번 한 번만** 앱을 지우고 새로 깔면서
키를 다시 넣어주세요. 그 다음부터는 새 APK 를 그냥 덮어 설치할 수 있고,
키도 매매법 기록도 그대로 이어집니다.

### 서명 키가 저장소에 있어도 되나요

이 키는 비밀이 아닙니다(구글의 기본 debug 키도 공개되어 있습니다). 본인 폰에
직접 설치해 쓰는 앱이라 이렇게 둡니다. 다만 **Google Play 에는 이 키로 올리면
안 됩니다** — 그때는 별도 키를 만들어 GitHub Secrets 에 넣어야 합니다.

백업 파일 쪽은 다릅니다. API 키가 들어가므로 AES-GCM 으로 암호화하고, 열쇠는
그 기기(ANDROID_ID)에 묶습니다. 파일만 빼가도 다른 기기에서는 풀 수 없습니다.

## 자동 업데이트

한 번 설치하면 앱이 6시간마다 이 주소를 봅니다.

```
https://github.com/tlsgusdlf33/autotrader/releases/latest/download/update.json
```

| | 어떻게 되나 |
|---|---|
| **매매 로직 (파이썬 엔진)** | **완전 자동.** 새 zip을 받아두고 엔진을 다시 띄우면 끝 — 설치도 탭도 없음 |
| **앱 자체 (화면·알림)** | 자동으로 받아두고 알림으로 알림. **설치 확인 탭 한 번** 필요 |

⚠️ 완전 무인 설치는 안드로이드가 막아둔 일입니다(스토어를 거치지 않은 앱은 설치마다
시스템 확인 창). 다만 매매 관련 개선은 대부분 엔진 쪽이라 실제로는 손댈 일이 거의 없습니다.

받은 파일은 **SHA-256을 확인한 뒤에만** 쓰고, 엔진 zip 3개 중 하나라도 실패하면
번들 번호를 올리지 않습니다(버전이 섞이는 것을 막기 위해).

**릴리스는 main 브랜치에서만 발행됩니다** — 작업 브랜치 빌드로는 자동 업데이트가
돌지 않습니다. 끄려면 설정 → 자동 업데이트 → `자동 끄기`.

## 매매법은 증권사별·시장별로 따로 켜고 끕니다

앱의 **매매법** 화면에서 켜고 끈 값은 **지금 보고 있는 증권사**에만 적용됩니다.
한국투자증권처럼 국내·미국을 같이 다루는 엔진은 화면 위의 **국내주식 / 미국주식**
버튼으로 시장까지 나눠서 정할 수 있습니다. 키움(국내)·업비트(원화)처럼 시장이
하나뿐이면 그 버튼은 나오지 않습니다.

| 예 | 결과 |
|---|---|
| 한투 · 미국주식에서 3번 끄기 | 한투 국내는 그대로, 미국에서만 3번이 빠집니다 |
| 한투 · 국내주식 전체 끄기 | 한투 미국과 키움·업비트는 영향 없습니다 |

예전에는 한 곳에서 끄면 켜둔 증권사 전부에서 같이 꺼졌습니다. 이제는 증권사마다,
시장마다 따로 저장됩니다. 업데이트 전에 꺼두었던 매매법은 두 시장 모두에 그대로
이어집니다 — 시장을 나눠 처음 저장하는 순간 그때의 상태가 양쪽에 복사됩니다.

⚠️ 여기서 끄는 것은 **새로 사는 것**만 막습니다. 이미 산 종목은 살 때 쓴 매매법으로
계속 관리됩니다.

## 매매법 백테스트

대시보드 안의 **매매법 백테스트** 카드에서 **백테스트 실행**을 누르면, 이미 받아둔
일봉으로 51개 매매법을 과거에 대입해 매매법마다 몇 번 신호가 났고 그중 몇 번
이겼는지 계산합니다.

표시 순서는 **거래가 많은 순 → 승률 높은 순**입니다(버튼으로 승률 우선으로 전환).
거래 횟수를 먼저 보는 이유는, 2번 신호가 나서 2번 맞은 승률 100%는 실력이 아니라
우연이기 때문입니다. 20건 미만인 승률은 흐리게 표시합니다.

| | |
|---|---|
| 데이터 | 엔진이 쌓아둔 일봉 캐시. **증권사에 새로 조회하지 않습니다** (업비트는 인증 불필요한 시세 조회 사용) |
| 매수 | 신호 **다음 날 시가** — 같은 날 종가로 계산하면 미래를 미리 본 셈이 됩니다 |
| 매도 | 그 매매법 자신의 매도·손절 조건 (안 걸리면 30거래일 뒤 강제 청산) |
| 비용 | 왕복 수수료·세금·슬리피지를 미리 뺍니다 (주식 0.25%, 업비트 0.1%) |
| 제외 | 분봉·호가가 필요한 12개(51번 포함)는 일봉으로 재현할 수 없어 측정하지 않습니다 |

### 결과는 증권사별 · 시장별로 따로 쌓입니다

한국투자증권은 **국내주식과 미국주식의 백테스트 결과가 완전히 분리**됩니다.
미국주식을 돌려도 국내주식 결과는 그대로 남고, 매수 우선순위도 각 시장이 자기
시장 승률만 씁니다. 자동 실행은 오래된 시장부터 번갈아 돕니다.

앱 매매법 화면의 **국내주식 / 미국주식** 버튼으로 시장을 바꾸면 매매법 on/off 와
백테스트 성적이 함께 그 시장 것으로 바뀝니다. 키움(국내)·업비트(원화)는 시장이
하나라 버튼이 없습니다.

⚠️ **v1.0.21 이전에 돌린 결과는 어느 시장 것인지만 표시되고, 나머지 시장은 비어
있습니다.** 그 시장으로 백테스트를 한 번 돌리면 채워집니다.

### 지수가 오를 때 / 내릴 때를 나눠서 봅니다

매매법마다 승률이 **▲ 상승 / ▼ 하락** 두 줄로 나옵니다. 합쳐진 승률 하나만 보면
판단을 그르치기 때문입니다. 실제 측정에서 이런 차이가 나왔습니다.

| 매매법 | 전체 | ▲ 지수 상승 | ▼ 지수 하락 |
|---|---|---|---|
| #21 수급 쏠림 전 눌림목 | 32% | 207회 **24%** | 116회 **46%** |
| #1 장대양봉 중심봉 눌림목 | 45% | 75회 **52%** | 19회 **16%** |
| #14 가짜 고점 거르기 | 18% | 64회 **11%** | 26회 **35%** |

같은 매매법이 시장 방향에 따라 정반대로 동작합니다. 지금 시장이 어느 쪽인지 보고
켜고 끄시면 됩니다.

**여기서 '지수'란** — 백테스트 대상 종목을 **같은 비중으로 묶은 지수**입니다.
그 지수가 자기 20일선 위면 상승으로 봅니다. 시가총액 가중을 안 쓴 이유는 시총을
따로 받아와야 하고, 몇 종목이 지수를 좌우해서 '시장 전체'를 보려는 목적과 어긋나기
때문입니다.

⚠️ 기준은 **신호가 난 날**입니다(매수한 날이 아니라). 그 판단으로 살지 말지가
갈리기 때문입니다. 20일선이 아직 안 그려지는 초반 날짜는 어느 쪽에도 넣지 않습니다 —
모르는 것을 '하락'으로 처리하면 하락장 승률이 오염됩니다.

⚠️ 한쪽 표본이 10건 미만이면 승률 뒤에 `?`가 붙습니다. 3건 중 2건 맞은 67%를 믿고
매매법을 끄면 우연을 따라가게 됩니다.

끝나면 매수 우선순위가 승률 높은 순으로 다시 세워집니다(재시작 불필요).
매매법을 실제로 빼려면 `.env`에 `STRATEGY_MIN_WIN_RATE_PCT` 같은 기준을 주세요.

⚠️ 매매 엔진과 같은 프로세스에서 돌아서 그동안 손절 감시가 조금 느려집니다 —
**장 마감 후**에 돌리는 것을 권합니다. 진행률·남은 시간이 표시되고 중단할 수 있습니다.

## 수익률 개선 설정

대시보드 **매매 설정**에 있습니다. **전부 기본이 '비어 있음 = 끔'** 이라, 넣지 않으면
예전과 똑같이 동작합니다.

| | 권장 | 하는 일 |
|---|---|---|
| ⚑ 전체 안전 손절(%) | **3~5** | 매매법이 뭐든 이 선에서 자릅니다. 51개 중 33개는 손절선이 차트 모양 기준이라 -10%까지 끌려갑니다 |
| ⚑ 전체 트레일링(%) | 5~8 | 고점 대비 이만큼 밀리면 익절 |
| ⚑ 최대 보유일 | 5~10 | 무기한 묶인 돈을 풀어줍니다 |
| ★ 승률 하한(%) 미만 제외 | 30~38 | 백테스트 승률이 낮은 매매법을 매수에서 뺍니다. **45로 두면 거래가 3% 수준으로 줄어듭니다** |
| ★ 익절 시 먼저 팔 비율(%) | 50 | 익절 신호에서 절반만 팔고 나머지는 들고 갑니다 |
| ★ 손실 종목 재매수 금지(일) | 3 | 손실로 판 종목을 이 기간 다시 사지 않습니다 |
| ★ 주워담기 기본 매매법 # | 35 | 기록 없는 보유 종목에 붙일 매매법 |
| ★ 시장 폭 하한(%) | **40** | 시장 전체가 약하면 새로 사지 않습니다 (아래 참고) |

`[51번]`이 붙은 익절·손절은 **51번 매매법만** 씁니다. 나머지 50개는 각자의 조건으로
판단합니다 — 화면에 표시를 갈라둔 이유입니다.

**주워담기 기본값을 #16 → #35 로 바꿨습니다.** #16은 매도가 `당일 시가 +3%`,
손절이 `전일 저가 붕괴`라 진입가를 전혀 보지 않습니다. #35는 익절 +8% / 손절 -4%를
둘 다 진입가 기준으로 봅니다. 바뀌는 것은 앞으로 주워담는 종목뿐이고, 이미 #16으로
기록된 보유 종목은 그대로입니다(보유 종목 줄의 `매매법 #16 ✎`으로 직접 바꿀 수 있습니다).

## 시장 폭 — 전체가 약할 땐 쉽니다

**시장 폭** = 지금 보고 있는 종목 중 **자기 20일선 위에 있는 것의 비율**입니다.
이 값이 설정한 하한보다 낮으면 **새로 사는 것만** 멈춥니다.

⚠️ **이미 들고 있는 종목은 그대로 관리됩니다.** 매도·손절은 평소대로 돕니다 —
시장이 나쁠 때 팔지 못하게 되면 그게 더 큰 손실입니다.

### 왜 넣었나 (숫자)

업비트 원화마켓 거래대금 상위 60종목 · 일봉 800봉(2024-07 ~ 2026-09) 실데이터로,
일봉 매매법 36개가 낸 신호 **43,404건**을 전부 따라가 봤습니다. 앞 구간에서 잰
성적으로 고르고 **그 다음 구간**에서 확인하는 방식(워크포워드) 4구간 합계입니다.

| | 거래 | 승률 | 거래당 평균 |
|---|---|---|---|
| 필터 없음 | 13,898 | 33.3% | **-0.854%** |
| 시장 폭 40% 초과일 때만 | 7,626 | **36.0%** | **+0.148%** |

승률만 오른 게 아니라 **거래당 기대값이 마이너스에서 플러스로 돌아섰고**, 4구간 중
3구간에서 둘 다 나아졌습니다. 하한을 35~60% 어디에 둬도 방향이 같아서, 특정 숫자에
맞춰 끼워맞춘 결과가 아닙니다.

여기에 기존의 승률 상위 매매법만 쓰는 방식을 겹치면 승률 32.9% → **40.7%**,
거래당 -0.949% → **+0.064%** 였습니다.

비교삼아 BTC 이동평균으로 판단하는 방식(예: BTC가 20일선 위일 때만)은 기대값은
비슷하게 좋아져도 승률은 +1~2%p에 그쳤습니다. **'대장 하나'보다 '전체가 같이
오르는 중인가'가 더 잘 맞았습니다.**

### 어떻게 재나

⚠️ **따로 조회하지 않습니다.** 매수 스캔이 어차피 종목마다 일봉을 받으므로 지나가는
길에 세기만 합니다 — 시세 조회가 한 번도 늘지 않습니다.

- 한 바퀴 다 돌면 그 값을 확정하고, **다음 바퀴부터** 판단에 씁니다(하루 단위로
  움직이는 값이라 한 바퀴 늦어도 차이가 없습니다).
- 증권사별·시장별로 따로 잽니다. 한투는 국내와 미국을 각각 봅니다.
- **못 쟀으면 막지 않습니다.** 표본이 30종목 미만이거나 측정이 6시간보다 오래됐으면
  '모름'으로 두고 평소대로 매매합니다 — 측정이 안 됐다는 이유로 매매가 멈추는 쪽이
